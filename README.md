# Hackathon Skills

해커톤 참가를 준비하며 사용할 디자인·글쓰기 스킬을 모아 둔 저장소입니다.

| 스킬 | 용도 |
| --- | --- |
| [frontend-design](skills/frontend-design/SKILL.md) | 웹 UI 디자인 |
| [hallmark](skills/hallmark/SKILL.md) | 디자인 검토·리디자인 |
| [humanize-korean](skills/humanize-korean/SKILL.md) | 한국어 문체 진단·윤문 |
| [humanizer](skills/humanizer/SKILL.md) | 자연스러운 문체로 글 다듬기 |

필요한 스킬은 [배포 파일](https://github.com/Loong-kid/hackathon-web-skills/releases/latest)에서 개별 다운로드할 수 있습니다.

각 스킬의 출처와 라이선스는 해당 폴더와 [출처 안내](THIRD_PARTY_NOTICES.md)에 기재되어 있습니다.
